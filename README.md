# pixelfire

C program using SDL2 that implements the classic "Doom" pixel fire algorithm. It creates an internal framebuffer (an array of pixels), updates the fire logic by seeding heat at the bottom and spreading it upward with randomized decay, and renders it to an SDL2 texture.
